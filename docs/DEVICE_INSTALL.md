# 경제 설계자 4.3.1 — 휴대폰 설치 및 실제 기기 확인

이 문서는 설치 절차이며 실제 기기의 설치 성공 보고서가 아니다. 공개 HTTPS 배포·CI 검증은 완료했으며 자세한 결과는 [PAGES_RESULT.md](PAGES_RESULT.md)에 있다. 실제 설치·아이콘 오프라인 재실행·OS 재부팅 결과는 사용자가 확인한 이후에만 기록한다.

## 학습 앱

**[경제 설계자 4.3.1 열기](https://soomin921123.github.io/economy-designer-test/index.html)**

현재는 테스트 저장소의 공개 정적 PWA이다. 사용자 로그인, 서버 동기화, APK/IPA, 앱스토어 등록은 이번 배포 범위가 아니다. 저장 키는 `econverse431-guarded`이며 자동 검사는 실제 사용자 프로필이 아닌 임시 환경의 합성 데이터를 사용했다.

## 먼저 기록을 보호한다

이전 파일 또는 다른 주소에서 학습했다면 해당 원래 환경의 '설정·백업 → 현재 기록 JSON 백업'으로 사본을 먼저 개인적으로 보관한다. 사이트 주소 또는 브라우저·설치된 앱이 다르면 기록을 자동으로 가져온다고 가정하지 않는다. 백업은 채팅·공개 GitHub에 업로드하지 않는다. 복원이 필요한 경우 새 환경의 '백업 선택·미리보기'에서 들어올 기록과 현재 기록을 비교한 다음에만 적용한다. 기존 학습 기록을 지우거나 브라우저 데이터를 초기화할 필요는 없다.

## iPhone — Safari

Safari에서 위 학습 주소를 직접 연다. ChatGPT나 메신저 안의 미리보기로 검사하지 않는다. 공유 메뉴에서 '홈 화면에 추가'를 선택한다. '웹 앱으로 열기'가 표시되면 켠 뒤 '추가'한다. 홈 화면의 경제 설계자 아이콘으로 다시 열고 온라인 상태에서 한 번 로딩한다.

Apple 공식 안내(확인일 2026-09-29): https://support.apple.com/ko-kr/guide/iphone/iphea86e5236/ios

## Android — Chrome

Chrome에서 위 학습 주소를 직접 연다. Google의 현재 안내 경로는 '더보기 → 설치 및 바로가기 만들기 → 설치'이다. 브라우저 버전에 따라 '홈 화면에 추가' 등의 이름으로 표시될 수 있으므로 해당 설치 안내를 따른다. 홈 화면의 아이콘으로 다시 열고 온라인으로 한 번 로딩한다. 단순 바로가기인지 독립 앱 창인지 구분해 기록한다.

Google 공식 안내(확인일 2026-09-29): https://support.google.com/chrome/answer/9658361?hl=ko&co=GENIE.Platform%3DAndroid

## 실제 기기에서 확인할 항목

1. 홈 화면 아이콘에서 열어 첫 화면과 단원 이동이 정상인지 확인한다.
2. 기존 기록의 사본을 보관한 상태에서 '움직임 줄이기' 등 되돌릴 수 있는 설정을 변경한다. 앱을 닫고 다시 열어 유지되는지 확인한다. 기존 답안을 검사 목적으로 덮어쓰지 않는다.
3. 온라인으로 앱을 한 번 연 뒤 비행기 모드를 켠다. Wi-Fi도 꺼졌는지 확인하고 앱을 완전히 닫은 다음 홈 화면 아이콘에서 다시 연다. 강의·단원이 열리는지 확인한다. 이후 네트워크를 복구한다.
4. 기기 재부팅 후 재실행은 위 결과와 별개로 확인한다. 실행하지 않았으면 '미실행'으로 남긴다.

## 결과를 전달할 때

기종 / OS 버전 / 브라우저 / 아이콘 설치 여부 / 독립 창 여부 / 앱 종료 후 설정·기록 유지 / 오프라인 아이콘 재실행 / 재부팅 후 재실행을 각각 '성공·실패·미실행'으로 적는다. 백업 JSON이나 개인 답안 대신 오류 문구와 개인정보를 가린 화면만 공유한다.
