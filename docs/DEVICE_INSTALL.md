# 경제 설계자 4.3.1 — 휴대폰 설치 및 실제 기기 확인

이 문서는 설치 절차이며, 설치 성공 보고서가 아니다. 실제 기기의 설치·오프라인 재실행·재부팅 결과는 사용자가 확인한 이후에만 기록한다.

## 대상

테스트 저장소의 기본 Pages 주소: https://soomin921123.github.io/economy-designer-test/index.html

배포 workflow의 성공과 공개 URL 확인 이후 사용한다. 현재 학습 앱은 단일 HTML의 정적 PWA이다. 사용자 계정 로그인, 서버 동기화, APK/IPA, 앱스토어 등록은 이번 배포 범위가 아니다. 사용자 저장 키는 `econverse431-guarded`이며 CI 검사는 실제 사용자 프로필 대신 격리된 합성 데이터를 쓴다.

## 먼저 기록을 보호한다

이전 파일 또는 다른 주소에서 학습했다면 해당 원래 환경의 '설정·백업 → 현재 기록 JSON 백업'으로 사본을 먼저 보관한다. 사이트 주소 또는 브라우저·설치된 앱이 다르면 기록을 자동으로 가져온다고 가정하지 않는다. 백업은 채팅·공개 GitHub에 업로드하지 않는다. 복원이 필요한 경우 새 환경의 '백업 선택·미리보기'에서 들어올 기록과 현재 기록을 비교한 다음에만 적용한다. 기존 학습 기록을 지우거나 브라우저 데이터를 초기화하는 절차는 요구하지 않는다.

## iPhone — Safari

Safari에서 위 학습 주소를 직접 연다. ChatGPT나 메신저 안의 미리보기로 검사하지 않는다. 공유 메뉴에서 '홈 화면에 추가'를 선택한다. '웹 앱으로 열기'가 표시되는 버전에서는 켠 뒤 추가한다. 홈 화면의 경제 설계자 아이콘으로 다시 열고 온라인 상태에서 한 번 로딩한다.

Apple 공식 안내(확인일 2026-09-29): https://support.apple.com/ko-kr/guide/iphone/iphea86e5236/ios

## Android — Chrome

Chrome에서 위 학습 주소를 직접 연다. 더보기 메뉴에서 '홈 화면에 추가 → 설치' 등 해당 브라우저에 표시되는 설치 메뉴를 사용한다. 홈 화면의 아이콘으로 다시 열고 온라인으로 한 번 로딩한다. 단순 바로가기만 추가된 것인지 독립 앱 창으로 실행되는지 구분하여 기록한다.

Google 공식 안내(확인일 2026-09-29): https://support.google.com/chrome/answer/9658361?hl=ko&co=GENIE.Platform%3DAndroid

## 실제 기기에서 확인할 항목

1. 홈 화면 아이콘에서 열어 첫 화면과 단원 이동이 정상인지 확인한다.
2. 기존 기록의 사본을 보관한 상태에서 '움직임 줄이기' 등 되돌릴 수 있는 설정을 변경한 뒤 앱을 닫고 다시 열어 유지되는지 확인한다. 기존 답안을 검사 목적으로 덮어쓰지 않는다.
3. 온라인으로 앱을 한 번 연 뒤 비행기 모드를 켠다. Wi-Fi도 실제로 꺼졌는지 확인하고 앱을 완전히 닫은 다음 홈 화면 아이콘에서 다시 연다. 강의·단원이 열리는지 확인한다.
4. 네트워크를 복구하고 기록이 유지되는지 확인한다. 기기 재부팅 후 재실행은 위 결과와 별개로 확인한다.

## 결과를 전달할 때

기종 / OS 버전 / 브라우저 / 아이콘 설치 여부 / 독립 창 여부 / 앱 종료 후 설정·기록 유지 / 오프라인 아이콘 재실행 / 재부팅 후 재실행을 각각 '성공·실패·미실행'으로 적는다. 백업 JSON이나 개인 답안 대신 오류 문구와 개인정보를 가린 화면만 공유한다.

주의: Chromium의 설치 가능 진단, 모바일 viewport 에뮬레이션, CI 브라우저 프로세스 재시작은 실제 휴대폰 홈 화면 설치·OS 재부팅 검증과 다르다.
