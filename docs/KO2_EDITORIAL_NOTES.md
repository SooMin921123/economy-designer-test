# 경제 설계자 4.3.1 — 문장 개정 2차 작업 기록

## 반영 기준

사용자가 검토한 13개 문체 예시를 기준으로 개념을 직접 설명하고, 계산의 이유와 과정을 풀어 썼다. 본문·해설은 설명체, 문제는 발문에 맞는 문장, 조작 안내는 짧은 존댓말로 구분하였다. 학생에게 불필요한 집필·출처 관리·판정 범위 설명을 본문에서 덜어 냈다. 필요한 계산 가정, 단위, 대안의 범위, 반환 규칙, 기록 교체 경고는 유지하였다.

기준은 저장소의 main 커밋 `d98c987d0581dd66e829f1d3ba8d9333c30916b4`이다. 이 커밋의 ko-1 원고와 비교하여 별도 작업 브랜치 `editorial/ko-2`에서 개정한다. 원본 보존 파일과 구문 오류 두 곳만 수정한 실행 기준본은 바꾸지 않는다. 이 문서의 작성과 작업 브랜치 커밋은 공개 사이트 배포가 아니다.

`editorial/ko2/refine.mjs`는 모든 영역의 대상 수를 확인한다. `prepare.mjs`는 ko-1과 ko-2의 정확한 변경 전후 문장을 비교표로 만든다. `audit.mjs`는 작성한 문자열이 실제 실행 데이터에 반영됐는지 확인하고 72강의 본문·예제·정리 탭을 각각 연다. 문장이나 숫자가 소스에만 있고 학생 화면에는 적용되지 않는 문제를 확인하기 위한 검사다.

## 문장 수정 외에 따로 기록할 변경

- **C01-05**: 종이 색으로 시대를 구분한다는 선택지를 없애고 중상주의·대공황·정책 목적을 비교하는 선택지로 수정하였다. 선택지 수와 정답 위치는 같다.
- **C06-07**: 담합의 직접적인 합의 자료와 가격의 일치·업체 수를 구별하도록 선택지를 다듬었다. 실제 기업 사건에 대한 법적 결론은 다루지 않는다.
- **C11-07**: 금융 위기와 안전성 선호의 관계를 직접 묻도록 문장 고치기 문제를 작성하였다. 고칠 부분과 정답 선택지의 위치는 유지하였다.
- **G07-1의 마지막 단계**: 실제 파업의 법적 판단 범위를 묻던 메타 질문을 단체 행동권의 의미를 묻는 질문으로 교체하였다. 이는 단순 말투 수정이 아니라 학습 질문의 변경이다. 노동 3권이라는 원래 학습 범위와 선택지 수, 정답 위치는 유지하였다.
- **R01-1**: ‘자료에서 이윤이라는 단어를 삭제한다’는 선택지를 경제활동의 금지에 관한 잘못된 주장으로 바꾸었다. 정답 위치는 유지하였다.
- **S1-3·C15-09·X15-1**: 정책 목적과 자료에서 알 수 있는 내용이 분명히 드러나도록 선택지를 재서술하였다. 정답이 되는 진술과 정답 위치는 유지하였다.

그 밖의 발문·해설 개정에서도 수치가 뜻하는 것이 달라지지 않도록 하였다. 특히 편익에서 명시적 비용을 뺀 금액을 순편익이라고 부르지 않는다. 기존 별칭인 ‘비교값’은 해당 계산식으로 풀어 썼다.

## 코드와 검사 규칙의 변경

학생 화면의 빈 주의란을 숨기고, 문단 안의 줄바꿈이 실제로 표시되도록 서식을 보완하였다. 학습 데이터를 지우거나 저장 구조를 변경하는 처리는 추가하지 않았다.

기존 앱의 내부 내용 검사에는 모든 심화 강의의 주의 문장이 10자를 넘어야 한다는 조건이 있었다. 불필요한 주의 문장을 삭제하기 위해 이 조건 하나를 ‘문자열이면 허용’으로 바꾸었다. 이는 문항 정답을 판정하는 함수가 아니라 내용의 필수 길이를 검사하는 규칙이다. 다른 실행 코드의 비문자열 구조 비교, 수치·정답 구조 비교, 36개 브라우저 회귀 검사는 유지한다. 이 변경을 숨긴 채 실행 코드가 한 글자도 바뀌지 않았다고 주장하지 않는다.
