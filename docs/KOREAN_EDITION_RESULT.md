학생 화면에서는 개발 이력을 개정 안내와 기능 점검으로 분리하고, 모호한 성공 메시지 대신 정답·오답을 명시했다. 참고 문서의 파일명과 문항 연결은 유지한다.

## 실제 검사 범위

두 환경에서 각각 다음을 검사했다.

1. 72강의 개념·예제·설명 탭과 확인 문제 정답 처리, 강의별 소제목 표시.
2. 정규·종합 219문항과 집중 탐구 36단계의 화면 생성, 페이지 수준의 가로 넘침 여부.
3. 단계별 풀이 30개를 실제 입력과 클릭으로 90단계까지 완료.
4. 기준본과 개정본의 숫자, 정답 데이터, 문항 식별자, 참조 연결 및 구조 대조.
5. 설정·정답·메모의 저장과 새로고침 유지, 분리된 브라우저 context의 독립성.
6. 관련 강의 왕복 후 답안 유지, 빈 슬라이더의 이동·새로고침 후 복원.
7. 실제 파일 선택을 통한 백업 미리보기와 취소, 알 수 없는 문항 ID 거부, 확인 후 복원 및 교체 전 기록 복구.
8. manifest와 service worker, 온라인 최초 접속 후 오프라인 새로고침과 새 탭 실행, 캐시 없는 오프라인 context의 실패 확인.
9. 내부 자가검사의 통과와 검사 전후 기록 보존, 개인 시험 표식이 제외된 PWA 내보내기 및 내보낸 파일의 오프라인 재실행.

## 중단 원인과 수정

초기 실행에서는 원고 JSON 문법 오류, 검사 대상 경로의 문자열 일치 오류, 모든 JSON을 개인 백업으로 취급하던 파일 정책 때문에 브라우저 검사 전에 중단되었다. 이 실행들은 브라우저 검사 통과로 집계하지 않았다.

문법과 경로 처리를 수정했다. 파일 정책은 원고용 정적 표·화면 문구의 JSON 구조를 검사하도록 바꾸었으며, 교재 PDF·HWP 등 원문 파일과 개인 학습 상태·복구 사본을 차단하는 조건은 유지했다. 최초 Drive 수집본과 실행 기준본의 바이트 대조도 그대로 유지했다.

진단용 스크립트에도 초기 오류가 있었고 수정 후 별도 컴파일 검사를 통과했다. 해당 진단 실행은 학습 앱의 브라우저 검사와 구분한다.

## 남아 있는 확인 범위

모바일 viewport 검사는 실제 iPhone·Android의 홈 화면 설치, 설치 아이콘 실행, OS 재부팅 검사가 아니다. 화면 생성과 정답 데이터 보존은 원교재의 모든 표·그림을 대조한 내용 전수 검수나 출간 승인도 아니다. 자유 서술은 자동 채점하지 않는다.

이번 작업은 `editorial/ko-431` 브랜치의 별도 개정판이다. **이 문서 작성 시점에는 기존 공개 학습 주소를 개정판으로 교체하지 않았다.** 공개 주소 검증 보고서 `PAGES_RESULT.md`는 이전 배포판의 결과이며 이번 문장 개정판의 공개 HTTPS 검증으로 인용하지 않는다.

기록 저장 키는 `econverse431-guarded`로 유지한다. 주소나 파일 경로·브라우저·기기를 바꾸면 기존 저장 공간과 달라질 수 있으므로 이동 전 외부 백업을 받아 두어야 한다.
