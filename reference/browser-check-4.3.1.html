경제 설계자 브라우저 검수

4.3.1 HTML 파일을 선택하면 학습 기록과 분리된 화면에서 검사합니다. 검사하기 전에는 통과 결과가 없습니다.

검사할 파일

이 프로젝트의 경제 설계자 HTML만 사용하세요. 선택한 파일을 읽어 실행하되 외부 네트워크 요청과 원래 브라우저 저장 공간의 접근을 제한한 별도 프레임을 사용합니다.

이 검수는 코드의 자가검사와 화면 생성, 일부 실제 입력·버튼 경로를 확인합니다. 실제 기기의 저장 유지·백업 파일 복원·오프라인 설치·전체 화면의 시각 교열·30시간 학습 효과는 별도입니다. 4.3.1에서는 구문 확인·초기화 실패·조작 검사를 나누고, 실패하면 이후 미실행 범위를 남깁니다. 미리보기·취소는 검사하지만 실제 저장소의 복원 적용은 이 분리 프레임에서 검사하지 않습니다. 검수 도구 자체도 제작자 환경에서는 실행하지 못했습니다.
